# User Story

## Historia

Como **usuario autenticado**, quero **cadastrar e editar meus idiomas** para **explicitar meu nivel de proficiencia de forma estruturada no curriculo**.

## Criterios de aceite

- [ ] O usuario consegue adicionar, editar e remover idiomas no curriculo.
- [ ] Cada idioma registra nivel de proficiencia de forma consistente.
- [ ] Os idiomas permanecem vinculados ao curriculo em edicao.
