# User Story

## Historia

Como **usuario autenticado**, quero **cadastrar e editar minhas habilidades** para **manter um inventario claro das competencias que podem ser destacadas em futuras adaptacoes**.

## Criterios de aceite

- [ ] O usuario consegue adicionar, editar e remover habilidades no curriculo.
- [ ] O sistema aceita nivel opcional por habilidade quando aplicavel.
- [ ] O sistema evita duplicidades obvias no mesmo curriculo.
