# User Story

## Historia

Como **usuario autenticado**, quero **escolher um template para uma versao do meu curriculo** para **definir a apresentacao final sem precisar remodelar o conteudo base**.

## Criterios de aceite

- [ ] O usuario consegue associar um template valido a uma versao do curriculo.
- [ ] A troca de template nao altera o conteudo factual armazenado na versao.
- [ ] A versao do curriculo passa a refletir o template selecionado nos fluxos seguintes.
