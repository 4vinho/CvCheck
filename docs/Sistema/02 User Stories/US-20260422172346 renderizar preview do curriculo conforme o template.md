# User Story

## Historia

Como **usuario autenticado**, quero **visualizar o preview do curriculo conforme o template escolhido** para **entender exatamente como o documento sera apresentado antes da exportacao**.

## Criterios de aceite

- [ ] O preview usa o schema canonico do curriculo como unica fonte de dados.
- [ ] O template organiza a exibicao de secoes conforme suas regras definidas.
- [ ] Secoes vazias seguem regras explicitas de exibicao sem quebrar a leitura do documento.
