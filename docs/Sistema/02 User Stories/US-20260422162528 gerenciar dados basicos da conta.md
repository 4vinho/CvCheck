# User Story

## Historia

Como **usuario autenticado**, quero **consultar e editar os dados basicos da minha conta** para **manter nome e email atualizados sem sair do escopo de autenticacao**.

## Criterios de aceite

- [ ] O usuario consegue visualizar os dados basicos da conta autenticada.
- [ ] O usuario consegue editar nome e solicitar alteracao de email.
- [ ] A mudanca de email so e efetivada depois da confirmacao do novo endereco informado.
