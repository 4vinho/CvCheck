# User Story

## Historia

Como **usuario autenticado**, quero **registrar o resumo profissional do meu curriculo** para **apresentar meu posicionamento de carreira de forma objetiva e reaproveitavel**.

## Criterios de aceite

- [ ] O usuario consegue criar, editar e remover o resumo profissional do curriculo.
- [ ] O sistema respeita o formato e o limite definidos para o resumo.
- [ ] O resumo fica associado apenas ao curriculo em edicao.
