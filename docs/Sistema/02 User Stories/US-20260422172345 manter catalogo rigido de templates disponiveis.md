# User Story

## Historia

Como **produto**, quero **manter um catalogo rigido de templates de curriculo** para **garantir consistencia de renderizacao e reduzir variabilidade tecnica na apresentacao**.

## Criterios de aceite

- [ ] O sistema disponibiliza um catalogo inicial fechado com tres templates.
- [ ] Cada template possui identidade visual, ordem de secoes e renderer definidos.
- [ ] Novos templates nao dependem de payload solto fora do schema canonico oficial.
