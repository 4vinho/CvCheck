# User Story

## Historia

Como **usuario autenticado**, quero **cadastrar e editar minhas experiencias profissionais** para **manter meu historico de trabalho estruturado e pronto para adaptacoes futuras**.

## Criterios de aceite

- [ ] O usuario consegue adicionar, editar e remover varias experiencias no mesmo curriculo.
- [ ] Cada experiencia segue uma estrutura padronizada de preenchimento.
- [ ] O usuario consegue indicar experiencia atual e definir a ordenacao exibida.
