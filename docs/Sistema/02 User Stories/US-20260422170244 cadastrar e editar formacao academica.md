# User Story

## Historia

Como **usuario autenticado**, quero **cadastrar e editar minha formacao academica** para **representar corretamente meu historico educacional no curriculo**.

## Criterios de aceite

- [ ] O usuario consegue adicionar, editar e remover varias formacoes no mesmo curriculo.
- [ ] Cada formacao segue uma estrutura padronizada de preenchimento.
- [ ] O usuario consegue indicar curso em andamento e manter a ordenacao das formacoes.
