# User Story

## Historia

Como **usuario autenticado**, quero **criar e gerenciar meus curriculos base** para **manter versoes diferentes do meu perfil conforme meus objetivos profissionais**.

## Criterios de aceite

- [ ] O usuario consegue criar mais de um curriculo dentro da propria conta.
- [ ] O usuario consegue listar e renomear curriculos ja criados.
- [ ] O usuario consegue definir qual curriculo e o principal para uso futuro na plataforma.
