# User Story

## Historia

Como **usuario autenticado**, quero **visualizar meu perfil curricular consolidado** para **entender rapidamente o estado do curriculo e identificar lacunas antes de reutiliza-lo**.

## Criterios de aceite

- [ ] O usuario consegue consultar uma visao unificada do curriculo selecionado.
- [ ] O sistema diferencia secoes preenchidas e secoes vazias.
- [ ] A visualizacao reflete corretamente o curriculo principal ou o curriculo selecionado pelo usuario.
