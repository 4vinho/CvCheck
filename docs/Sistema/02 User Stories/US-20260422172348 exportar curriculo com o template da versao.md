# User Story

## Historia

Como **usuario autenticado**, quero **exportar o curriculo usando o template da versao atual** para **obter um documento final coerente com o preview que revisei**.

## Criterios de aceite

- [ ] A exportacao usa o mesmo template definido para a versao do curriculo.
- [ ] O resultado exportado preserva a mesma organizacao visual vista no preview.
- [ ] A exportacao nao exige remodelagem manual do conteudo para cada template.
