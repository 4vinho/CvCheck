# Regra de Negocio

## Descricao

A geracao adaptada deve resolver o curriculo fonte exclusivamente dentro do conjunto pertencente ao usuario autenticado, usando o curriculo explicitamente selecionado quando informado ou, na ausencia dele, a regra oficial do curriculo principal ou selecionado do perfil base.
