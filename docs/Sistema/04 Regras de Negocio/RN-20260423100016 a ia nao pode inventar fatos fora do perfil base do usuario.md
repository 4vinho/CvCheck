# Regra de Negocio

## Descricao

A IA nao pode inventar experiencias, resultados, certificacoes, tecnologias, formacoes, idiomas ou qualquer outro fato ausente do perfil base oficial do usuario, ainda que o texto da vaga sugira desejabilidade ou alinhamento com tais itens.
