# Regra de Negocio

## Descricao

A autenticacao oficial do produto deve ser implementada sobre `ASP.NET Core Identity`, que passa a ser a base padrao para criacao de conta, login, confirmacao de email, recuperacao de senha, contas externas e manutencao de credenciais.

- [[US-20260422162527 entrar ou criar conta com google]]
- [[US-20260422162528 gerenciar dados basicos da conta]]
