# Regra de Negocio

## Descricao

Todos os templates de curriculo devem consumir o mesmo schema canonico de conteudo, evitando contratos diferentes por template e reduzindo acoplamento entre apresentacao e dominio.

- [[FEAT-20260422172338 templates de curriculo]]
